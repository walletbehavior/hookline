# Rolling activity and Tape recovery, October 9, 2026

Hookline now makes the last 24 hours legible before a user reads the feed.

## Rolling activity summary

The Activity page adds exact rolling 24-hour totals for factory launches, implementation changes, fee and configuration changes, observed outcomes, and active projects. Project leaders in the same window link directly to their profiles.

The summary is computed from canonical monitored records, excludes historical backfill, and is independent of the visible feed's 60-row response limit. Selecting a project narrows the summary to that project. Feed signal, evidence, and history filters continue to control the visible rows without rewriting the underlying daily totals.

At the October 9 rollout check, the preceding 24 hours contained 717 non-backfill monitored records: 588 Doppler factory launches, 108 Clanker token launches, 16 Clanker fee-claim records, and five observed CLAUS implementation changes. These are point-in-time chain observations, not rankings, endorsements, or claims about economic quality. Creator-supplied token names and metadata remain untrusted text.

## Tape ingestion recovery

The Base Tape transport now preserves an actionable smaller-range response from a reviewed provider when another fallback cannot serve archive data. Initialize and Swap scans recursively retry legitimate response-size limits in bounded smaller windows. Cursors still move only after a successfully decoded and saved segment.

This fixes a failure mode where a free archive rejection could mask a second provider that was able to answer the same request in a smaller window. Provider throttling, block-identity mismatches, and chain mismatches still fail closed.

## API and cache correctness

`GET /api/project-activity` is schema version 4 and includes `summary24h`. The edge-cache key now includes the mechanism-signal filter so one signal view cannot reuse another signal's cached rows.

## Verification

The rollout includes the full project evidence, contribution, Projects UI/API, mechanism subscription, account, wallet, trading preference, Tape, worker, and transport regression suites. New coverage verifies mixed archive/range provider behavior, bounded Tape window retries, exact summary aggregation, safe project-name rendering, and signal-specific cache separation.
